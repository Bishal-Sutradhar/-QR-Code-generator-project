# ⚡ QR Code Generator

A simple yet smart **QR Code Generator** built using **HTML, CSS, and JavaScript**.  
It instantly creates QR codes for any text or URL and lets you **download them as images**.

---

## ✨ Features

- 🔹 Generate QR from any text or link  
- 🔹 Responsive design (auto resizes for mobile)  
- 🔹 Download QR as PNG  
- 🔹 Lightweight

## 🧩 Tech Used

- **HTML5** – Page structure  
- **CSS3** – Styling  
- **JavaScript** – Core logic  
- **QRCode.js** – For generating QR codes
